# GitPilot

Cliente Git de escritorio para macOS (Electron + React): **múltiples cuentas** (correo, llave SSH, token), **varios repos en pestañas**, grafo de commits, Gitflow, staging por hunk/línea, conflictos, stash, tags, remotos, submódulos y consola Git integrada.

```bash
npm install && npm start            # probar ya
./scripts/build-mac.sh --install    # compilar GitPilot.app e instalarla en /Applications
```

- 📘 [Manual de usuario](docs/MANUAL_USUARIO.md)
- 🛠 [Manual técnico](docs/MANUAL_TECNICO.md)

Requisitos: macOS, Node.js 20+, git. Pruebas: `npm test`.
